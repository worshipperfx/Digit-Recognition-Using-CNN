# Digit Recognition Using CNN

This project implements a **Convolutional Neural Network ** for classifying handwritten digits using the **Functional API** in **Keras**. The model is trained on the **MNIST dataset**, which contains 70,000 grayscale images of digits from 0 to 9.

---

##  Project Summary

- **Project Title**: Digit Recognition Using Functional CNN  
- **Author**: Marvellous Chitenga  
- **Dataset**: MNIST (from Keras datasets)  
- **Model Type**: CNN using Functional API  
- **Accuracy Achieved**: ~98% on test data  
- **Platform**: [Kaggle Notebook](https://www.kaggle.com/code/marvellouschitenga/cnn-digit-recognition-algorithm)

---

## Key Features

- Functional API architecture for flexibility
- Deep CNN with Convolutional, Pooling, Dropout, and Dense layers
- Clean and modular code structure
- Visualization of predictions and evaluation metrics
